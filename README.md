# АС — Telegram Bot Setup

Резервная копия текущего состояния Telegram-бота и схемы AS-CORE.

## Состав резервной копии

- `supabase/functions/as-telegram-bot/index.ts` — исходник Edge Function, извлечённый непосредственно из активного Supabase-проекта, версия 10.
- `supabase/schema_snapshot.sql` — снимок структуры БД по фактической схеме проекта.
- `supabase/types/database.types.ts` — типы TypeScript, сгенерированные Supabase.
- `docs/backup-manifest.md` — параметры источника и состав копии.
- `docs/restore.md` — инструкция по восстановлению.

## Важные ограничения и безопасность

1. Секреты, токен Telegram, service-role key и значения переменных окружения в репозиторий не помещаются.
2. На момент снимка все 10 прикладных таблиц были пустыми. Данные клиентов не экспортировались.
3. `schema_snapshot.sql` — интроспекционный снимок текущей схемы, а не оригинальные SQL-файлы применённых миграций.
4. Резервная копия находится в отдельной ветке `backup/as-core-snapshot-20261126`, основная ветка `main` не изменялась.
5. Рабочая функция Supabase и Telegram webhook не изменялись.
6. Репозиторий GitHub публичный. В него помещён только исходный код и схема без секретов и клиентских данных. Если требуется закрытый репозиторий, видимость нужно отдельно изменить в настройках GitHub.
